종이 모서리 4곳 저장

로봇을 직접 종이의 모서리로 옮긴 뒤 "현재 위치 저장"을 누르세요. 모서리 저장은 로봇을 움직이지 않고 읽기만 해요. (움직이는 건 아래 "펜 들기 테스트"뿐이에요)

연결 안 됨

다른 로봇 패널(webcontrol, 포트 5000)과 동시에 같은 로봇에 연결하지 마세요.

현재 위치: -
시계 방향으로 저장하는 걸 추천해요: 1 왼쪽 위 → 2 오른쪽 위 → 3 오른쪽 아래 → 4 왼쪽 아래

펜 끝 · 기울기 보정

모서리를 저장할 때 펜이 조금씩 다르게 기울어져도 되도록, 저장한 TCP 에서 펜 끝까지 길이를 알려 주면 펜 끝 위치로 환산해서 종이 평면(판이 기울어진 것 포함)을 만들어요. 도구 TCP 가 이미 펜 끝에 설정되어 있으면 아래 체크만 하고 길이는 0으로 두세요. 모르면 "도구 TCP 확인"을 눌러 보세요(읽기만 해요). 펜 끝 위치를 알면 "펜을 종이에 수직으로 세우기"도 쓸 수 있어요.

펜 끝은 그 자리에 두고 손목만 돌리기

위에서 펜 끝 오프셋을 정해 두었으면, 펜 끝이 닿아 있는 점은 그대로 두고 펜(손목)만 기울이거나 판에 수직으로 세울 수 있어요. 속도 15% 이하, 한 번에 60° 이하로 2°씩 이어서 돌아요. 먼저 "미리 계산"을 눌러 보세요(로봇은 읽기만 해요).

펜 끝 자동 교정 (한 점에 대고 자세 바꿔 저장)

종이(또는 판) 위 한 점에 펜 끝을 대고, 그 점을 벗어나지 않게 손목만 앞·뒤·좌·우로 다르게 기울여서 그때마다 "이 자세 저장"을 누르세요(4번 이상, 서로 20° 이상 다르게). 그러면 펜 끝까지 길이(z)와 옆으로 나온 정도(x, y)를 계산해요. 모서리를 저장할 때와 같은 도구(TCP) 설정에서 해야 해요. 이 단계는 로봇에 읽기 명령만 보내요(움직이지 않아요).

저장한 자세 없음

펜 들기 테스트 (뒤로 갔다가 앞으로)

다른 선으로 옮길 때처럼, 도구 Z축(J6 방향)으로 조금 뒤로(−) 갔다가 다시 앞으로(+) 와요. 펜이 도구 +Z 방향으로 종이를 향해 있다고 가정해요. 처음엔 종이에서 멀리 떨어진 허공에서 "뒤로만"을 눌러, 펜이 종이에서 멀어지는 방향이 맞는지 먼저 확인하세요.

사각 구역 한 바퀴

저장한 모서리 1 → 2 → 3 → 4 → 1 순서로 직선 이동해요. 시작은 모서리 1 위쪽으로 접근하니, 펜을 모서리 1 근처(25cm 이내)에 두고 시작하세요. 먼저 "경로 보기"로 이동할 좌표를 확인하세요.

원통 그리기 (공중)

저장한 사각 구역 가운데에서, 종이에서 펜 쪽으로 떠 있는 공중에 아래 원 → 위 원 → 세로선 4개를 끊김 없이 한 번에 그려요. 펜이 종이에 닿지 않아요. "종이에서 펜 쪽"은 저장한 펜 방향의 반대쪽이에요(바닥 종이면 위, 세운 판이면 로봇 쪽). 이 로봇은 명령 큐를 볼 수 없어서(CNDE 안 붙음), 로봇의 실제 위치를 계속 읽으며 지나간 점보다 8개까지만 앞서 보내 끊김 없이 이어요. 먼저 "위치 읽기 확인"을 눌러 보세요.

SVG 그림 그리기

MindDraw가 그린 그림(PNG)은 선 굵기를 깎은 중심선으로 바꿔 SVG 획으로 만든 뒤 그려요(윤곽을 따라가면 한 선을 두 번 그려서요). 사진·PNG·JPG를 올려도 같아요. SVG 파일(또는 예시)을 저장한 사각 구역 안에 비율을 지켜 맞추고, 획마다 펜 들기 → 이동 → 내리기 → 그리기를 반복해요. 전체를 끊김 없이 이어서 보내요(원통과 같은 방식). 곡선(스플라인)을 켜면 획마다 컨트롤러 스플라인(NewSpline)으로 점들을 부드러운 곡선으로 지나가요(이 로봇에서는 아직 시험 전이라, 처음엔 처음 N획만을 2~3으로 해서 공중 연습하세요). 모든 도형의 윤곽선을 따라 그려요(채우기는 그리지 않아요). 먼저 "경로 보기"로 방향을 확인하세요: 어느 모서리가 위쪽인지는 저장 순서에 달려 있어서 회전으로 맞춰요. 처음에는 공중 연습으로 해 보세요.
