# 로봇 그림 그리기 도구 (paper_points)

Fairino FR5 협동로봇이 종이(판) 위에 **그림을 실제로 그리게** 하는 웹 도구입니다.
마음그림봇(MindDraw Bot, `../painting`)이 만든 선화(PNG)를 선(획)으로 바꿔서, 저장한 종이 구역에 맞춰 로봇이 따라 그립니다.

- 실행: `python app.py` → <http://localhost:5051> (conda 환경 `claude`)
- 로봇 연결: 화면 맨 위에서 IP 입력 후 "연결" (기본 `192.168.58.2`)
- 마음그림봇(웹, 5050)은 별도 프로그램입니다: `../painting` (자체 저장소, 문서는 `../painting/minddraw_project.md`)

> 현재 이 폴더는 git에 커밋되어 있지 않습니다(`git status`에서 untracked). 사용자 데이터 파일은 `.gitignore`에 들어 있습니다.

## 1. 전체 흐름

```
MindDraw 그림(PNG) ─┐
사진·PNG·JPG ───────┼→ [중심선 변환 + 내부 채우기] → SVG(획 목록)
SVG 파일 ───────────┘                                    │
                                                         ▼
모서리 4곳 저장 ─→ 종이 평면(기울기 포함) ─→ [종이에 맞추기·획 순서·경로] ─→ 로봇
펜 끝 오프셋(교정) ─┘        (펜 끝 위치 기준으로 계산)
```

사용 순서(처음 한 번 + 그릴 때마다)

1. **연결** → 로봇 IP로 연결
2. **모서리 4곳 저장** — 로봇을 손으로 움직여 펜 끝을 종이 모서리 1→2→3→4(한 방향) 순서로 대고 "현재 위치 저장"
3. **펜 끝 보정**(한 번) — "펜 끝 자동 교정"으로 펜 끝 오프셋(x, y, z)을 계산해 적용하거나, 길이를 직접 입력
4. **그림 고르기** — MindDraw 그림 / 파일 업로드 / SVG / 예시
5. **경로 보기** — 원본과 "로봇이 그릴 모습"(펜 굵기 반영)을 나란히 확인, 슬라이더·펜 굵기 조절
6. **공중 연습**(종이에 안 닿음)으로 먼저 돌려 보기 → 문제 없으면 **종이에 그리기**

## 2. 기능

| 카드 | 하는 일 |
|---|---|
| 종이 모서리 4곳 | 현재 TCP 자세 저장·삭제. 저장·삭제 때마다 `paper_points_history.jsonl`에 이전 값이 남음 |
| 펜 끝 · 기울기 보정 | 펜 끝 오프셋(x, y, z) 또는 "도구 TCP가 이미 펜 끝" 설정, 펜을 판에 수직으로 세우기 옵션, 평면 확인(판 기울기·평면성·펜 기울기 차이·경고), 도구 TCP 확인(읽기) |
| 펜 끝은 그 자리에 두고 손목만 돌리기 | 펜 끝 오프셋을 알 때, 펜 끝을 고정한 채 손목만 돌려 판에 수직으로 세우거나 4방향으로 기울임(속도 ≤15%, 한 번에 ≤60°) |
| 펜 끝 자동 교정 | 한 점에 펜 끝을 대고 자세를 바꿔 4번 이상 저장 → 최소제곱으로 오프셋(x, y, z) 계산 → 적용 |
| 펜 들기 테스트 | 도구 Z축으로 뒤로 갔다가 앞으로(펜 올리고 내리기 점검) |
| 사각 구역 한 바퀴 | 저장한 4모서리를 공중(또는 종이에 닿게) 한 바퀴 |
| 원통 그리기(공중) | 위·아래 원 + 세로선 4개를 끊김 없이 한 번에 |
| **SVG 그림 그리기** | 이 도구의 핵심. 아래 §3 |

화면 맨 위 "저장한 세팅": 그리기 카드의 입력값 전부를 이름 붙여 저장·불러오기(`paper_presets.json`). 새로고침해도 마지막 입력값은 브라우저에 유지됩니다. 현재 저장된 세팅: "보드마카 2mm"(펜 2.0), "펜 0.2mm"(펜 0.2).

## 3. SVG 그림 그리기

### 3.1 그림 → 획 (`vectorize.py`)

MindDraw 그림은 선이 굵어서(약 5px) 윤곽을 따라가면 한 선을 두 번 그립니다. 그래서:

1. 회색조 → 이진화(Otsu) → 작은 얼룩 제거 → **중심선(thinning)**
2. 끝점·분기점 사이를 획으로 추적하고, 분기점에서는 가장 곧게 이어지는 획끼리 한 획으로 잇기
3. **펜보다 굵은 부분**(굵은 윤곽선, 눈동자, 점)은 윤곽을 따라 안쪽으로 한 겹씩 **고리로 채움**(내부 채우기). 펜보다 가는 선은 중심선 한 줄
4. 펜이 굵으면(그림 속 7px 이상) 펜보다 작은 디테일(작은 구멍·잔선)은 같이 정리
5. 단순화(RDP) 후 SVG로 내보냄 (`data-pen-px`에 펜 굵기 기록)

핵심 개념: **펜 굵기(mm)** 를 알려 주면, 이 종이에 이 그림을 맞췄을 때의 배율(mm/px)로 그림 속 펜 굵기(px)를 계산해 변환합니다. 펜이 가늘수록 굵은 선을 여러 번 겹쳐 그려 원본과 같게 만들고(점·시간 증가), 굵으면 단순해집니다.

### 3.2 디테일 슬라이더 (0~100%)

값이 낮을수록 작은 얼룩·짧은 선·곁가지·점을 더 버리고 점 간격·오차를 크게 잡습니다. 움직이면 약 0.5초 뒤 같은 그림을 다시 변환하고 경로 미리보기를 갱신합니다. 100%는 "최대 디테일": 점·아주 짧은 선도 1mm 점 찍기로 남기고, 점 간격·오차를 펜 굵기에 맞춰 촘촘히(펜 0.2mm면 점 간격 약 0.3mm).

`art_001` 기준(펜 0.8mm): 0% → 78획 / 25% → 112 / 50% → 148 / 75% → 182 / 100% → 185획.

### 3.3 획 → 로봇 경로 (`paper_draw.py`)

- 저장한 사각 구역 **안에 비율을 지켜** 맞춤(여백, 크기 %, 90° 회전, 좌우 반전). 구역 밖이면 자동으로 줄임
- 가까운 획부터 순서 정하기, 끝이 1.5mm 이내면 펜을 들지 않고 이어 그림
- 획마다 펜 들기 → 이동 → 내리기 → 그리기 (공중 연습은 `공중 높이` 만큼 띄워서 그림)
- 곡선은 호 길이 기준으로 고르게 다시 찍되 35° 이상 꺾이는 모서리는 보존
- 미리보기: 원본(왼쪽)과 로봇이 그릴 모습(오른쪽, 펜 굵기 반영, 모서리 번호 표시)

### 3.4 두 가지 실행 방식

| | **직선 이음 (권장, "곡선(스플라인)" 끔)** | 곡선(스플라인) |
|---|---|---|
| 방식 | MoveL을 `blendR`(비블로킹)로 연달아 보내 정지 없이 이음. 로봇의 실제 TCP 위치를 읽어 지나간 점을 따라가며 앞쪽 8개까지만 보냄 | 획마다 컨트롤러 스플라인(`NewSplineStart/Point/End`), 짧은 조각은 이음 이동, 펜 들기·내리기는 끝까지 기다리는 이동 |
| 장점 | 끊김 없는 연속 동작. 점 간격 1~1.5mm면 곡선처럼 보임 | 컨트롤러가 곡선을 만듦 |
| 단점 | 점이 많고 속도가 높으면 점을 못 따라 보내 끊길 수 있음("끊겼을 수 있는 횟수" 표시) | **끝점·동작 전환마다 정지**해서 속도 30% 이상에서 덜컹거림이 확인됨 |

스플라인이 안 움직이거나 거부되면 정지 후 같은 조절점을 직선 이동으로 대신 이어 가며 횟수를 표시합니다.

### 3.5 속도

- 그리기 속도: 1~100% (제한을 풀었음). 곡선만 따로 속도를 정하는 입력도 있음
- 그 외 동작(펜 들기 테스트, 사각 구역, 원통, 펜 끝 고정 회전)은 15% 이하

## 4. 펜 끝 보정 (손으로 저장한 모서리의 기울기까지 반영)

수학적으로: 저장한 TCP 위치 `p`, 자세 `R`, 도구 좌표계의 펜 끝 오프셋 `t`일 때 **펜 끝 = p + R·t**.

- 네 모서리를 모두 펜 끝 위치로 환산해서 종이 평면을 만들기 때문에, 저장할 때 펜이 조금씩 다르게 기울어도 되고 판이 기울어져 있어도 됩니다(평면 법선은 네 점의 대각선 외적).
- 로봇에 보낼 때는 `TCP = 펜 끝 − R'·t`로 되돌립니다 (사각 구역, 원통, SVG 직선 이음·곡선 모두 같은 함수 `paper_loop.tcp_pose` 사용).
- **모서리 4곳만으로는 펜 길이를 알 수 없습니다**(기울기 차이가 작으면 길이가 평면 모양에 거의 영향이 없어 추정 오차가 170mm). 그래서 오프셋은 아래 중 하나로 정합니다.
  1. 플랜지에서 펜 끝까지 길이를 자로 재서 입력
  2. **자동 교정**: 펜 끝을 한 점에 댄 채 자세만 바꿔 4번 이상 저장 → 최소제곱 `p_i + R_i·t = c` (시뮬레이션 오차: 자세 변화 ±20°에서 평균 0.9mm, ±30°에서 0.6mm. 펜이 옆으로 나온 x, y도 구함)
  3. 로봇 티치펜던트에서 도구(TCP)를 펜 끝에 설정하고 "도구 TCP가 이미 펜 끝" 체크(오프셋 0)
- 시뮬레이션(판 3° 기울임, 모서리별 펜 ±4° 흔들림, 펜 길이 150mm, TCP가 플랜지): 보정 전에는 그림이 옆으로 최대 9mm 밀리고(펜이 판에서 20° 기울면 높이 오차 최대 3.9mm), 펜 길이를 입력하면 0.3mm 이하.
- **펜 끝 고정 회전**(`paper_pen.py`): 오프셋을 알면 펜 끝을 고정한 채 손목만 돌릴 수 있음. 2°씩 중간 자세를 만들어 이어 보내며 계산상 펜 끝 흔들림 0.0mm.
- 현재 적용된 값(`paper_settings.json`): z 269.0 / x −15.7 / y −2.6 mm, 수직 세우기 꺼짐. 교정용 자세 5개 중 5번째(15:42)는 다른 점이라 목록에서 지워야 "계산하기"가 통과합니다(적용된 값에는 영향 없음).

## 5. 계산 예시 (`art_001`, 선 굵기 약 5px)

원본 검은 부분과 그려질 모양이 겹치는 비율(일치도), 여백 10mm.

| 종이 | 그림 크기 | 펜 1.0mm | 펜 2.0mm |
|---|---|---|---|
| A4 | 약 190×198mm | 85% | 56% |
| A2 | 약 400×416mm | 86% | **87%** |

- 지금 저장된 종이(약 269×179mm 가로)에서는 세로 179mm가 한계라 그림이 약 144×150mm입니다. 펜 2.0mm는 그림 속 약 12px라 눈 같은 작은 디테일이 뭉개집니다(원본 선의 2.6배).
- 펜 0.2mm에서는 건너뛴 선 0개, 점 약 3만 개, 선 길이 약 9.6m, 일치도 86%(눈·하이라이트·입까지 원본과 거의 같음). 시간이 오래 걸려 처음에는 "처음 N획만"으로 시험하는 것을 권장.
- 펜이 가늘수록 점·시간 증가, 굵을수록 디테일 감소.
- A2는 도달 범위(FR5 922mm), 판 평평함, 변 길이 600mm 제한을 먼저 확인해야 함.

## 6. 안전장치

- 모든 이동 전: "주변이 비어 있고 정지 버튼 옆에 손이 있음" 확인 체크 필수. 종이에 닿게 그릴 때는 별도 확인
- 로봇 에러코드가 있으면 거부, 동시에 한 동작만, 정지(Esc, 별도 연결로 `StopMotion`) 후에는 다음 이동을 보내지 않음
- 시작점 거리 ≤250mm(첫 접근은 직선 이동), 변 길이 30~600mm, 펜-법선 각도 ≤60°(20° 넘으면 경고), 평면성 5mm 초과 경고, 저장 순서 꼬임 감지
- 위치 읽기 실패 5회, 6초 이상 진행 없음, 컨트롤러 거부 시 즉시 정지
- 펜 끝 고정 회전: 펜 끝 오프셋을 모르면 거부, 한 번에 60° 이하, 손목 이동 450mm 이하, 계산상 펜 끝 흔들림 0.5mm 초과 시 거부
- 사용자 데이터는 덮어쓰거나 지우기 전에 이력(`paper_points_history.jsonl`)에 남김

## 7. 실로봇에서 확인된 것 / 아직 모르는 것

확인됨
- 위치 읽기(`GetActualTCPPose`, XML-RPC)로 진행을 따라가는 방식이 동작함(이 로봇은 CNDE 상태 수신이 안 붙음)
- `NewSpline*` 스플라인은 동작함(획 1~9 완료, 16점 29mm 곡선 포함). 단, 5mm짜리 3점 스플라인 하나가 움직이지 않은 적이 있어 짧은 조각은 이음 이동으로 대체
- 속도 20% 이하는 문제없고 30% 이상에서 곡선 모드의 끝점·동작 전환에서 덜컹거림 → 직선 이음 모드로 해결을 시도 중(사용자 피드백: "매우 좋구만")

아직 모름
- 직선 이음 모드의 고속(30% 이상)에서 "끊겼을 수 있는 횟수"가 어느 정도인지
- `NewSplineStart`의 `averageTime`(곡선 시간)이 정확히 무엇을 뜻하는지(속도에 영향을 주는지)
- `blendR=0`·작은 blend의 컨트롤러 동작 세부, 아주 많은 점(3만 개)을 보낼 때의 시간
- 종이에 닿게 그릴 때의 실제 펜 높이(보드마카 눌림), 판 평평함에 따른 오차
- 펜 끝 오프셋(269 / −15.7 / −2.6mm)이 맞는지: **"사각 구역 한 바퀴"를 종이에 닿게로 돌려 네 모서리에 펜이 닿는지** 확인하면 검증됨
