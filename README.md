# FR5

FAIRINO FR5 협동로봇 Python SDK를 리눅스 환경 기준으로 정리한 개인
참고용 저장소입니다. 공식 `fairino-python-sdk`의 중국어 예제 150여
개를 기능별로 재구성하고 한국어로 번역했습니다.

자세한 내용은 [`code/README.md`](code/README.md)를 확인하세요:

- `code/fairino/` - SDK 본체
- `code/examples/` - 카테고리별로 정리된 한국어 예제 (연결/활성화,
  이동, I/O, 힘제어, 안전, 좌표계, 상태/로그, 외부축/컨베이어, 용접,
  그리퍼, 스크립트/Lua, 시스템/버전, Modbus/485, 고급 궤적)

원본: [FAIR-INNOVATION/fairino-python-sdk](https://github.com/FAIR-INNOVATION/fairino-python-sdk)
